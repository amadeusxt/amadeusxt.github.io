安卓笔记——Kotlin篇

一.初识Kotlin

一.关于变量

Kotlin 拥有类型推导机制，因此声明变量只需要两个关键字：val 和 var。
val（value）：声明不可变变量，赋值后不能修改
var（variable）：声明可变变量，值可以随时修改

补充：Kotlin每一行的代码结尾不需要分号（祖宗之法被改变了）

Kotlin 的数据类型单词与 Java 基本一致，但首字母必须大写
这是因为 Kotlin 中的数据类型全部都是类，而非 Java 中的基本数据类型

二.函数

函数在 Kotlin 中就相当于 Java 里的方法，
定义 Kotlin 函数时，必须在前面加上关键字 fun

自定义函数的格式是fun+函数名(参数名:参数的数据类型（可以不填）):返回的数据类型（要返回就写，不返回不写）

得益于Kotlin语法的简便，如果函数体只有一行代码，可以用Kotlin的语法糖简化函数

构造函数

Kotlin 将构造函数分为主构造函数和次构造函数两类，是类实例化的核心逻辑载体

主构造函数

核心特点
最常用的构造函数，无函数体，直接定义在类名后方
类默认自带无参主构造函数，也可显式声明带参数的主构造函数
主构造函数参数可声明为val/var，会自动成为类的成员字段

主构造函数无函数体，若需编写初始化逻辑，需通过init 结构体实现，所有主构造函数的逻辑都写在init内：

继承规则
子类主构造函数必须调用父类构造函数（遵循 Java 继承规范）
若父类有无参构造函数：子类主构造函数后接()调用（即使无参也不能省略）
若父类有带参构造函数：子类主构造函数需显式传递参数给父类构造函数

参数注意事项
子类主构造函数若需添加与父类同名的参数（如name/age），不能加 val/var，仅作为主构造函数的形参，避免与父类字段冲突

次构造函数

核心特点
可定义多个，有函数体，通过constructor关键字声明
类可同时拥有主构造函数和多个次构造函数
所有次构造函数必须直接或间接调用主构造函数（通过this关键字）

调用规则
次构造函数通过this(参数)调用主构造函数，完成参数传递
次构造函数之间也可通过this()互相调用，最终需指向主构造函数

类继承与构造函数关联
父类构造函数要求
父类若显式声明带参构造函数，默认无参构造函数会消失，子类必须显式调用父类带参构造函数。

五.接口

接口是实现多态编程的重要组成部分
Kotlin 和 Java 一样，类只能单继承父类，但可以实现多个接口
接口用于定义抽象行为，由具体的类来实现

Kotlin 中继承父类和实现接口统一使用冒号 :，用逗号分隔
接口后不需要括号（无构造函数）
实现接口方法时，必须使用 override 关键字

接口的多态特性
实现了接口的类实例，可以传入接收该接口类型参数的函数中
这就是 面向接口编程（多态） 的体现

接口方法的默认实现
Kotlin（及 Java 8+）允许为接口中的方法提供默认实现（即带函数体）
实现类必须重写无默认实现的抽象方法
对于有默认实现的方法，实现类可以选择重写，也可以直接使用默认逻辑

Kotlin 有 4 种可见性修饰符，与 Java 存在一些差异

修饰符 Kotlin 规则 Java 对应规则
public 默认，对所有类可见 仅对同包内可见（Java 默认是包访问权限）
private 仅当前类内部可见 仅当前类内部可见
protected 当前类、子类可见 当前类、子类、同包类可见
internal 同一模块内所有类可见 无直接对应（类似包访问权限的扩展）

七.集合函数式 API

filter 与 map 函数

filter：根据条件过滤集合元素，返回满足条件的新集合
map：将集合中的每个元素映射为另一个值，返回映射后的新集合

all：判断集合中所有元素是否都满足指定条件，返回Boolean

九.Kotlin 空指针检查（可空类型系统）

Kotlin 在编译期进行空指针检查，杜绝运行时空指针异常（NPE）。
默认类型：不可空类型（如String、Study），变量 / 参数默认不可为null。
可空类型：在类型后加?表示可空（如String?、Study?），必须显式处理空值。

判空辅助工具
（1）安全调用运算符 ?.
作用：对象不为空时调用方法 / 属性；对象为空时返回null，不执行操作。
简化判空逻辑，替代if (obj != null)

（2）Elvis 运算符 ?:
作用：表达式不为空时返回自身；为空时返回右侧的默认值。
常与?.结合使用，处理空值默认情况

（3）非空断言运算符 !!
作用：强制将可空类型转为非空类型，若对象为空则抛出空指针异常。
风险较高，仅在 100% 确定对象不为空时使用

（4）let 函数
作用：将对象作为参数传入 Lambda 表达式，对象不为空时执行 Lambda；为空时不执行。
优势：可处理全局变量的判空问题（if语句无法处理），避免重复判空。

十二.延迟初始化和密封类

对变量延迟初始化

有些全局变量会被多个函数共用，为了减少重复的空判断代码，可以使用 lateinit 关键字

作用：告诉 Kotlin 编译器：这个变量我会在晚些时候再初始化，暂时不用强制做空安全检查

lateinit 只能修饰 var 可变变量

只能用于非空类型

必须在使用前完成初始化，否则会报错

可以用 ::变量名.isInitialized 判断是否已经初始化

密封类是一种受限的继承结构，关键字为 sealed class，主要作用是：
定义一组有限且固定的子类集合，子类只能在与密封类同一个文件中声明
配合 when 语句使用时，编译器会强制检查所有子类分支，无需写 else 兜底，避免漏处理分支

传统方式 vs 密封类 对比

传统接口方式（存在隐患）

问题：

代码更简洁，消除了无意义的 else 分支

运算符重载基础

Kotlin 允许对运算符（如 + - * / 等）进行重载，通过 operator 关键字实现，让自定义对象支持运算符操作
运算符重载本质是语法糖，编译时会自动转换为对应的函数调用（如 a + b → a.plus(b)）
重载运算符需遵循逻辑合理性，例如 Money 对象相加有意义，Student 对象相加则无意义

语法规则
使用 operator 关键字修饰函数
函数名需与运算符一一对应（如 + 对应 plus，- 对应 minus）
支持对同一运算符进行多重重载（如 Money + Money 和 Money + Int）

运算符 实际调用函数 说明
a + b a.plus(b) 加法
a - b a.minus(b) 减法
a * b a.times(b) 乘法
a / b a.div(b) 除法
a % b a.rem(b) 取模
a++ a.inc() 自增
a-- a.dec() 自减
+a a.unaryPlus() 正号
-a a.unaryMinus() 负号
!a a.not() 逻辑非
a == b a.equals(b) 等于
a > b / a < b a.compareTo(b) 比较
a in b b.contains(a) 包含（注意顺序反转）
a..b a.rangeTo(b) 区间
a[b] a.get(b) 索引访问

内联函数

每次调用 Lambda 表达式都会创建匿名类实例，会带来额外的内存分配开销

为了减小损耗，可以使用内联函数

工作原理（代码替换）
Kotlin 编译器会在编译期做两步替换，彻底消除 Lambda 带来的开销：
替换 Lambda 表达式：将 Lambda 代码直接替换到高阶函数中调用它的位置
替换内联函数本身：将整个内联函数的代码，直接替换到调用它的地方
最终效果：原本的函数调用和匿名类创建，会被直接替换成普通代码执行，没有额外开销
noinline 与 crossinline 关键字

noinline：排除部分参数的内联
场景：当高阶函数接收多个函数类型参数，只想对部分参数进行内联时使用
用法：在不需要内联的参数前添加 noinline 关键字

限制：noinline 修饰的函数类型参数，不能传递给其他内联函数。

crossinline：解决非局部返回冲突
场景：内联函数中，函数类型参数被传递给匿名内部类（如 Runnable）时，return 关键字会产生冲突
问题原因：内联函数允许 Lambda 中使用 return 直接返回外层函数，但匿名内部类中无法直接返回外层函数
解决方法：在参数前添加 crossinline 关键字，禁止 Lambda 中使用 return 进行非局部返回，只允许局部返回

内联函数的返回规则

非内联高阶函数
Lambda 表达式中只能使用局部返回，格式为 return@函数名，仅退出当前 Lambda 代码块，不会影响外层函数的执行

内联高阶函数
Lambda 表达式中可以直接使用 return 关键字，实现非局部返回，直接退出外层调用函数（如 main）

适用场景：绝大多数高阶函数都可以声明为 inline，尤其是函数类型参数会被直接调用的场景
不适用场景：
函数类型参数被存储（如赋值给变量），而非直接调用时，无法内联
函数类型参数被传递给其他非内联函数时，需要配合 noinline 使用
crossinline 的补充：声明 crossinline 后，Lambda 中无法使用 return 非局部返回，但仍可使用 return@函数名 局部返回
